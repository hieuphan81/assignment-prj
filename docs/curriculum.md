# Curriculum map

## Selection

The project uses **Toán 10 – Kết nối tri thức với cuộc sống**, Tập 1 and
Tập 2. This choice is now reflected in the requirements, README, demo guide,
and SQL seed. The chapter and lesson titles below follow the textbook
contents. Lesson explanations, examples, and practice questions in this
application are project-created content; they are not copied from the book.

The seed creates all nine topics and 27 published lessons. Each lesson has
concise original notes with a core idea, a worked example, and a takeaway.
It also provides at least one published sample MCQ and one sample essay
question for every lesson. Bài 16 has an additional sample essay question for
demonstrating written-work review.

## Content completion policy

The seeded notes and practice questions are starting material, not a substitute
for teacher review. Teachers should verify mathematical correctness and
alignment, expand the explanations, and add optional video/resource links as
appropriate. The demo seed uses inactive sample accounts; create active
accounts through the application for a live demo.
